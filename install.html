U50 Pro 控制台 · 迷你版

v1.7.1 · 不用电脑 · 在原厂页面里运行
第 1 步：复制收藏夹代码
点下面的按钮，代码会复制到剪贴板。
已复制 ✓
第 2 步：存进 Safari 收藏夹
打开任意网页 → 分享 → 添加到个人收藏 → 保存；然后书签 → 编辑 → 点开刚存的那条 → 把网址栏里的内容全删掉，粘贴刚才复制的代码 → 完成。收藏夹名字改成 U50 控制台。
第 3 步：打开控制台
手机连着 U50 的 Wi-Fi，Safari 打开 http://192.168.0.1，等原厂页面加载完，点地址栏输入 U50 控制台，点收藏夹那条，控制台就出来了。输密码自动进入。
迷你版有什么
登录（自动进入）、信号 / 流量 / 电池总览、Wi-Fi 双频合一开关、接入设备、未读短信。短信管理、高级设置等完整功能在电脑版里。
